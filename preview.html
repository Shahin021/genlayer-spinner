The five phases are exactly a fifth of a cycle apart, so no two seats ever hold the same value and there is no frame where the mark flattens into one uniform state. During a crossfade a fourth seat is briefly non-zero; each settled state is a clean 3-of-5.

Colour

Three official values, nothing else

Kinetic Cobalt at full strength measures 2.4:1 on Carbon Void, under the 3:1 floor for non-text graphics, so the dark accent is Cobalt mixed 70/30 with Ceramic Node — #5554FC, 3.9:1. The seat track is 18% Carbon Void over Ceramic Node on light (#CACACA) and 18% Ceramic Node over Carbon Void on dark (#323232). No fourth colour is introduced; each value is written as a color-mix() of the official three, with a hex fallback.

Theming

Which file to use where

genlayer-spinner.svg follows prefers-color-scheme, which is the operating system's setting, not the colour of the container it sits in. Inline it and override --gl-active and --gl-track to drive it from the Portal's own theme. If it has to be an <img> on a surface whose theme the Portal controls independently, use genlayer-spinner-light.svg or genlayer-spinner-dark.svg — fixed palettes, no media query, so they cannot disagree with the surface.

The official GenLayer mark asset is never modified or animated. Quorum is a separate loading component derived from its geometry.
